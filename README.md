# SkopjeMods

Mods for Skopje 83 using BepInEx IL2CPP.

## Instructions to install mods

1. Download BepInEx 6 IL2CPP
https://builds.bepinex.dev/projects/bepinex_be

Version: Artifact 789
File: BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.789+6cea286.zip

2. Launch game once to initialize BepInEx classes and folders

3. Drop mods in plugins and config where needed
